# Paradise Nursery Shopping Application

## Project Name
**Paradise Nursery Shopping Application**

## Project Description
Paradise Nursery is an online plant shopping application designed to make it easy for users to explore and shop for indoor plants. The application provides a simple shopping experience where users can browse different categories of plants, view product details, add plants to their shopping cart, and manage their selected items.

## Project Objectives
- Provide an easy-to-use online plant shopping experience.
- Display houseplants in different categories.
- Allow users to add and remove plants from the shopping cart.
- Enable users to increase or decrease product quantities.
- Calculate item totals and the overall cart amount dynamically.
- Create a clear and user-friendly shopping interface.

## Key Features
- **Landing Page:** Displays the Paradise Nursery name and a Get Started button.
- **About Us:** Provides information about the company, its mission, and its offerings.
- **Plant Categories:** Organizes plants into categories for easy browsing.
- **Product Listing:** Displays plant images, names, and prices.
- **Add to Cart:** Allows users to add plants to their shopping cart.
- **Shopping Cart:** Displays selected plants, quantities, prices, and the total amount.
- **Quantity Management:** Allows users to increase or decrease quantities.
- **Remove Items:** Enables users to delete plants from the cart.
- **Continue Shopping:** Allows users to return to the product listing.
- **Checkout Message:** Displays a Coming Soon message for the checkout feature.

## Technologies Used
- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Router
- Git and GitHub

## Project Structure
The project includes the following main files:

- `README.md` — Project documentation.
- `AboutUs.jsx` — Company information.
- `App.jsx` — Landing page.
- `App.css` — Styling and landing page background.
- `CartSlice.jsx` — Shopping cart state management and reducer functions.
- `ProductList.jsx` — Plant product listing.
- `CartItem.jsx` — Shopping cart interface and quantity management.

## How to Use
1. Open the application.
2. Click the Get Started button to access the plant shopping experience.
3. Browse the available plant categories.
4. Add your preferred plants to the cart.
5. Open the cart to manage quantities or remove items.
6. Review the total amount before checkout.

## Conclusion
The Paradise Nursery Shopping Application demonstrates the basic functionality of an online plant store, including product browsing, category-based listings, shopping cart management, quantity updates, and dynamic price calculation.
